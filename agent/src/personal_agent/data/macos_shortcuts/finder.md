# Finder 단축키

단축키는 macOS 버전과 사용자 설정에 따라 달라질 수 있습니다. 실제 Finder 메뉴에 표시된 키 조합이 다르면 메뉴 안내를 우선합니다.

| 번호 | 동작 | 키 조합 | 적용 범위 및 비고 |
|---:|---|---|---|
| 031 | 선택 파일 복제 | `⌘ D` | Finder |
| 032 | 선택 디스크 꺼내기 | `⌘ E` | 디스크 또는 볼륨 선택 시 |
| 033 | Finder 검색 시작 | `⌘ F` | Finder에서 검색 창 열기 |
| 034 | 선택 파일 정보 보기 | `⌘ I` | 정보 가져오기 창 |
| 035 | 선택한 별칭의 원본 표시 | `⌘ R` | 별칭을 선택한 경우 |
| 036 | 컴퓨터 위치 열기 | `⇧ ⌘ C` | Finder |
| 037 | 데스크탑 폴더 열기 | `⇧ ⌘ D` | Finder |
| 038 | 최근 항목 열기 | `⇧ ⌘ F` | Finder의 최근 항목 |
| 039 | 폴더로 이동 창 열기 | `⇧ ⌘ G` | 경로 입력 가능 |
| 040 | 사용자 홈 폴더 열기 | `⇧ ⌘ H` | 현재 로그인한 사용자 |
| 041 | iCloud Drive 열기 | `⇧ ⌘ I` | Finder |
| 042 | 네트워크 위치 열기 | `⇧ ⌘ K` | Finder |
| 043 | 다운로드 폴더 열기 | `⌥ ⌘ L` | Finder |
| 044 | 문서 폴더 열기 | `⇧ ⌘ O` | Finder |

| 052 | 상태 막대 표시 또는 숨기기 | `⌘ /` | Finder 윈도우 |
| 053 | 보기 옵션 열기 | `⌘ J` | Finder 윈도우 |
| 054 | 서버에 연결 창 열기 | `⌘ K` | Finder |
| 055 | 선택 항목의 별칭 만들기 | `⌃ ⌘ A` | Finder |
