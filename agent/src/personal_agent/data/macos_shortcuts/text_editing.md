# 텍스트 편집 단축키

앱과 텍스트 입력 영역의 동작에 따라 달라질 수 있습니다.

| 번호 | 동작 | 키 조합 | 적용 범위 및 비고 |
|---:|---|---|---|
| 077 | 선택 텍스트 굵게 | `⌘ B` | 서식을 지원하는 앱 |
| 078 | 선택 텍스트 기울임 | `⌘ I` | 서식을 지원하는 앱 |
| 079 | 선택 텍스트에 링크 추가 | `⌘ K` | 서식을 지원하는 앱 |
| 080 | 선택 텍스트 밑줄 | `⌘ U` | 서식을 지원하는 앱 |
| 081 | 서체 패널 표시 또는 숨기기 | `⌘ T` | 텍스트 편집 앱에 따라 다름 |
| 082 | 커서 왼쪽 단어 삭제 | `⌥ Delete` | 텍스트 입력 중 |
| 083 | 커서 왼쪽 문자 삭제 | `⌃ H` | Delete 키와 같은 방향 |
| 084 | 커서 오른쪽 문자 삭제 | `⌃ D` | 또는 `fn Delete` |
| 085 | 커서 오른쪽 문자 삭제 | `fn Delete` | Forward Delete 키가 없는 키보드 |
| 086 | 커서부터 문단 끝까지 잘라내기 | `⌃ K` | 앱에 따라 별도 임시 클립보드 사용 |
| 087 | 잘라낸 텍스트 붙여넣기 | `⌃ Y` | `⌃ K`와 같은 앱 안에서 사용 |
| 088 | 한 페이지 위로 이동 | `fn ↑` | 문서 편집 또는 스크롤 영역 |
| 089 | 한 페이지 아래로 이동 | `fn ↓` | 문서 편집 또는 스크롤 영역 |
| 090 | 문서 시작으로 이동 | `fn ←` | Home 동작 |
| 091 | 문서 끝으로 이동 | `fn →` | End 동작 |
| 092 | 문서 시작으로 커서 이동 | `⌘ ↑` | 텍스트 편집 앱 |
| 093 | 문서 끝으로 커서 이동 | `⌘ ↓` | 텍스트 편집 앱 |
| 094 | 현재 줄 시작으로 커서 이동 | `⌘ ←` | 텍스트 편집 앱 |
| 095 | 현재 줄 끝으로 커서 이동 | `⌘ →` | 텍스트 편집 앱 |
| 096 | 이전 단어 시작으로 이동 | `⌥ ←` | 텍스트 편집 앱 |
| 097 | 다음 단어 끝으로 이동 | `⌥ →` | 텍스트 편집 앱 |
| 098 | 줄 또는 문단 시작으로 이동 | `⌃ A` | 앱에 따라 줄/문단 기준이 다름 |
| 099 | 줄 또는 문단 끝으로 이동 | `⌃ E` | 앱에 따라 줄/문단 기준이 다름 |
| 100 | 커서를 한 문자 앞으로 이동 | `⌃ F` | 텍스트 편집 앱 |
