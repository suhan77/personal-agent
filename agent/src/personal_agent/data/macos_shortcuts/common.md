# macOS 공통 및 시스템 단축키

Apple 공식 안내를 바탕으로 자주 쓰는 단축키를 정리했습니다. `⌘` Command, `⇧` Shift, `⌥` Option, `⌃` Control, `fn` Fn 또는 Globe 키를 뜻합니다.

단축키는 앱, macOS 버전, 키보드 배열, 사용자 설정에 따라 달라질 수 있습니다. 실제 앱 메뉴에 표시된 키 조합이 다르면 메뉴 안내를 우선합니다.

| 번호 | 동작 | 키 조합 | 적용 범위 및 비고 |
|---:|---|---|---|
| 001 | 선택 항목 복사 | `⌘ C` | 대부분의 앱, Finder 파일에도 적용 |
| 002 | 선택 항목 잘라내기 | `⌘ X` | 대부분의 앱 |
| 003 | 클립보드 내용 붙여넣기 | `⌘ V` | 대부분의 앱 |
| 004 | 실행 취소 | `⌘ Z` | 대부분의 앱 |
| 005 | 다시 실행 | `⇧ ⌘ Z` | 실행 취소의 반대 동작 |
| 006 | 모두 선택 | `⌘ A` | 현재 문서 또는 창 |
| 007 | 찾기 창 열기 | `⌘ F` | 현재 문서 또는 앱에 따라 다름 |
| 008 | 다음 찾기 결과 | `⌘ G` | 이전 검색어 기준 |
| 009 | 이전 찾기 결과 | `⇧ ⌘ G` | 이전 검색어 기준 |
| 010 | 현재 앱 숨기기 | `⌘ H` | 앱 창을 닫지 않고 숨김 |
| 011 | 다른 앱 숨기기 | `⌥ ⌘ H` | 현재 앱만 보이게 함 |
| 012 | 앞쪽 창 최소화 | `⌘ M` | Dock으로 최소화 |
| 013 | 현재 앱의 모든 창 최소화 | `⌥ ⌘ M` | 앱이 지원하는 창에 적용 |
| 014 | 항목 열기 | `⌘ O` | 선택 항목 또는 파일 열기 대화상자 |
| 015 | 프린트 대화상자 열기 | `⌘ P` | 앱이 프린트를 지원해야 함 |
| 016 | 현재 앱 종료 | `⌘ Q` | 저장되지 않은 변경 사항 확인이 나올 수 있음 |
| 017 | 문서 저장 | `⌘ S` | 문서가 있는 앱 |
| 018 | 새 탭 열기 | `⌘ T` | 지원하는 앱 |
| 019 | 앞쪽 창 또는 탭 닫기 | `⌘ W` | 앱 자체는 종료하지 않음 |
| 020 | 현재 앱의 모든 창 닫기 | `⌥ ⌘ W` | 지원하는 앱 |
| 021 | 강제 종료 창 열기 | `⌥ ⌘ Esc` | 응답하지 않는 앱 선택 가능 |
| 022 | 전체 화면 켜기 또는 끄기 | `⌃ ⌘ F` | 전체 화면을 지원하는 앱 |
| 023 | 앱 전환 | `⌘ Tab` | 열린 앱 사이 전환, Tab을 반복해 선택 |
| 024 | 현재 앱의 창 전환 | ⌘ + grave accent 키 | 키보드 배열에 따라 키 위치가 다름 |
| 025 | 설정 열기 | `⌘ ,` | 앞쪽 앱의 설정 또는 환경설정 |
| 026 | 전체 화면 스크린샷 | `⇧ ⌘ 3` | 화면 전체 캡처 |
| 027 | 선택 영역 스크린샷 | `⇧ ⌘ 4` | 드래그로 캡처 영역 선택 |
| 028 | 스크린샷 및 화면 기록 도구 열기 | `⇧ ⌘ 5` | macOS Mojave 이상 |
| 029 | 화면 잠그기 | `⌃ ⌘ Q` | 사용자 로그인 상태 유지 |
| 030 | Spotlight 열기 또는 닫기 | `⌘ Space` | 입력 소스 전환 단축키와 충돌할 수 있음 |
