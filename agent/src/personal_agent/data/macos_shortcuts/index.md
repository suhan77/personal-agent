# macOS 단축키 문서 안내

각 파일은 적용 범위별 단축키를 담고 있습니다. `common.md`는 시스템과 여러 앱에서 쓰는 단축키이며, 앱별 문서는 해당 앱 항목만 포함합니다.

| 파일 | 대상 |
|---|---|
| `common.md` | macOS 공통 및 시스템 |
| `finder.md` | Finder |
| `spotlight.md` | Spotlight |
| `text_editing.md` | 텍스트 편집 |

앱이 지정된 질문에는 공통 문서와 해당 문서를 함께 사용합니다. 앱이 지정되지 않은 일반 질문에는 전체 문서를 사용합니다.

한 앱의 문서가 길어지거나 독립된 주제가 늘어나면 해당 앱 폴더를 만들고 주제별 Markdown 파일로 나눕니다. 이때 도구의 파일 목록과 패키징 설정도 함께 갱신합니다.
