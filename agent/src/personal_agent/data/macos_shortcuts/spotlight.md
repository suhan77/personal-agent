# Spotlight 단축키

Spotlight 단축키는 macOS 버전과 설정에 따라 달라질 수 있습니다.

| 번호 | 동작 | 키 조합 | 적용 범위 및 비고 |
|---:|---|---|---|
| 066 | 검색 결과 훑어보기 | `Space` | Spotlight 결과를 선택한 상태 |
| 067 | 다음 검색 결과로 이동 | `↓` | Spotlight 검색 창 |
| 068 | 이전 검색 결과로 이동 | `↑` | Spotlight 검색 창 |
| 069 | 검색 결과 경로 표시 | `⌘` | Spotlight 검색 창에서 결과 선택 |
| 070 | 검색 결과 열기 | `Return` | Spotlight 검색 창 |
| 071 | 결과 파일을 Finder에서 보기 | `⌘ R` | 파일 검색 결과 선택 시 |
| 072 | 앱 결과로 좁히기 | `⌘ 1` | Spotlight 검색 결과 |
| 073 | 파일 결과로 좁히기 | `⌘ 2` | Spotlight 검색 결과 |
| 074 | 동작 결과로 좁히기 | `⌘ 3` | Spotlight 검색 결과 |
| 075 | 클립보드 결과로 좁히기 | `⌘ 4` | Spotlight 검색 결과 |
| 076 | 검색 결과 필터 시작 | `/` | Spotlight 검색 창 |
